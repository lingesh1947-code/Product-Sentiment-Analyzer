connect_mongodb()

Database connection function

What it does: Connects Python to MongoDB database and returns the collection where reviews will be stored.
python connect_mongodb()
def connect_mongodb():
    uri = "mongodb://localhost:27017/"
    client = MongoClient(uri)
    db = client["sentiment_analyzer"]
    collection = db["amazon_reviews"]
    return collection
  • MongoClient Connects Python to MongoDB server running on your computer
  • database sentiment_analyzer = your project's database name
  • collection amazon_reviews = like a table, stores each review as one row
  • return Returns the collection so other functions can save data into it

setup_driver()

Browser setup function

What it does: Creates and configures a Chrome browser that Selenium will control automatically.
python setup_driver()
options.add_argument("--headless")     # No window
options.add_argument("--no-sandbox")    # Prevent errors
options.add_argument("user-agent=Mozilla/5.0...")  # Fake real browser
driver = webdriver.Chrome(options=options)
  • --headless Browser runs invisibly — no window opens on screen
  • user-agent Makes Chrome pretend to be a real human browser so Amazon doesn't block us
  • webdriver Selenium takes control of Chrome — it can click, type, scroll automatically
⚠️ If you get ChromeDriver error, run: pip install webdriver-manager and add ChromeDriverManager().install()

Searches Amazon and finds the product

driver.get("https://www.amazon.in")

scrape_reviews_from_page()

Most important function — extracts all review data

What it does: Reads the HTML of the reviews page and extracts all fields from each review block — reviewer name, star rating, title, body text, date, verified status.
python Review extraction
# Find ALL review blocks on the page
review_blocks = soup.find_all("div", {"data-hook": "review"})

for block in review_blocks:
    reviewer = block.find("span", {"class": "a-profile-name"}).get_text()
    stars    = block.find("i", {"data-hook": "review-star-rating"})
    title    = block.find("a", {"data-hook": "review-title"}).get_text()
    body     = block.find("span", {"data-hook": "review-body"}).get_text()
  • find_all() Finds EVERY review block on the page — returns a list
  • for block in Loop — processes each review one by one
  • data-hook Amazon uses this HTML attribute to identify review elements
  • try/except If any field is missing, it won't crash — uses a default value instead
  • sentiment: None Left empty — NLP team (Role 7) will fill this with Positive/Negative/Neutral

go_to_next_page() + Pagination

Scrapes multiple pages of reviews

What it does: After scraping one page, clicks the "Next" button and repeats. Continues until max_pages is reached or no next button found.
python Pagination loop
for page_num in range(1, max_pages + 1):
    page_reviews = scrape_reviews_from_page(driver, product_title)
    save_to_mongodb(collection, page_reviews)

    has_next = go_to_next_page(driver)
    if not has_next:
        break   # No more pages, stop loop
  • max_pages=3 By default scrapes 3 pages — each page has ~10 reviews = ~30 reviews total
  • li.a-last a Amazon's CSS selector for the Next page button
  • break Stops the loop when there's no next page
💡 3 pages = ~30 reviews. Change max_pages=5 for 50 reviews.

save_to_mongodb()

Saves reviews to database without duplicates

What it does: Saves each review into MongoDB. Before saving, checks if the same review already exists to avoid duplicates.
python save_to_mongodb()
for review in reviews:
    exists = collection.find_one({
        "reviewer_name": review["reviewer_name"],
        "review_title": review["review_title"]
    })
    if not exists:
        collection.insert_one(review)   # Save to MongoDB
  • find_one() Checks if a review with same name + title already exists in DB
  • insert_one() Saves one review document into MongoDB collection
  • duplicate check Prevents saving same review twice if you run scraper again
✅ MongoDB automatically creates an _id field for each document as unique identifier.
